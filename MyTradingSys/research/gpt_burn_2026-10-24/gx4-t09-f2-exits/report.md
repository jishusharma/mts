The per-layer backtests below used other exits, and some only measured forward returns rather than simulating an executable exit. Therefore a purported per-layer fix must not infer a live exit from forward-return horizons.

Independent arithmetic from `MyTradingSys/backtest/layers/FORMULAS.md` section 2 (population SD convention; section 12 ATR uses a plain mean of TR) does not provide or justify any layer exit settings. I therefore do not invent stop/target/horizon numbers. A bracket is only “matched” when its explicit values and mechanics are recorded in the layer params and correspond to the backtest implementation. Existing RSI bracket constants at `run_rsi_backtest.py:55-58` provide a backtest specification, while the two RSI params files do not contain exit settings.

## Proposal (not applied)

`patch.diff` sketches the fail-closed seam. It expects each traded layer to provide its own params document with an `exits` block. No shared bracket fallback is allowed. Existing layer param documents currently lack a complete exit block; therefore accepted alerts from those layers will be rejected until backtest-derived values and semantics are added. Forward-return horizons are not executable exit rules. Keep the layer-to-param-file resolver explicit and reviewed, especially for subfamilies with different backtests. Any per-layer exit spec must also preserve tested entry mode, stop-first ordering, and timeout bar clock where those are part of the backtest.

**Fail-first test required:** `test_layer_signal_rejects_when_exit_params_missing` — with a valid, promoted alert and mocked missing/unreadable/invalid layer params, assert `reject` is set, `plan_args` is absent, and no executor is invoked. This must fail against current code because `layer_signal` currently builds plan args from shared defaults without consulting layer params. Add companion cases for valid distinct layer specs and time-bar conversion; live-path test coverage also needs restart/reset state, non-trade balance moves, and API errors per CLAUDE.md.

Result: Confirmed S1: the universal live bracket has no layer-specific backtest parity; missing exit params must fail closed.
