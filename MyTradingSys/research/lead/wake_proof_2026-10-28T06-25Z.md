# Wake proof: a sleeping headless session, woken by one one-shot `schtasks /IT` task (2026-10-28, JIS-NUC)

What this proves (the task card `wake-sleeping-sessions`): a **sleeping** (idle, no live turn) Claude session is woken with **zero operator step** by a single one-shot Windows scheduled task, the woken session can **read its own usage** (handed to it, not only readable live), it **does its work**, and the task **unregisters itself**. Proven on this NUC only. No other station's session was woken or messaged.

## The gap it closes
Before the fix, `successor_wake.py` registered the one-shot task but handed the woken successor only the `SUPERVISOR_<L>.md` hand-over. The woken session had **no way to read its own usage/budget** unless it was live and could call `get_usage` — which a gateway-profile session (the NUC) cannot, and a sleeping one never reaches. The pacer's last `get_usage` reading already lived on disk (`~/.claude/mts-superloop/<login>-last-plan.json`) but nothing surfaced it to the boot prompt. The fix adds a **usage handoff**: a `USAGE` JSON written next to the task's `prompt.txt`, named in the boot prompt, so the woken session reads its own budget off disk and then records a fresh reading.

## The mechanism (all local, one one-shot task, self-unregistering)
- Tool: `scripts/dev/successor_wake.py register` (new code on this branch) — the same one-shot `Register-ScheduledTask -LogonType Interactive` pattern as `nuc_wake.py` / SCHEDULING_POLICY §4b2, **minus** the SSH gate: it runs locally as the logged-in Windows user **e-ngineers**.
- It writes `F:/MTS/succ_wake/B/prompt.txt` (the boot prompt), `F:/MTS/succ_wake/B/USAGE` (the usage handoff, JSON), `F:/MTS/succ_wake/B/run.ps1` (boots `claude -p` headless via `conhost --headless`, unregisters the task in a `finally`), then `Register-ScheduledTask MTS-SuccWake-B` + `Start-ScheduledTask` (fire now).
- One trigger only, no repeat (`-Once` / start-now path). The 4b2 rule "must be unregistered after it fires" is the `finally` in `run.ps1`.

## Proof on this NUC (steps + real logs)
1. Prompt written to `F:/MTS/succ_wake/B/proof_prompt.txt`: read the `USAGE` handoff, write one `WAKE_PROOF ...` line to `F:/MTS/succ_wake/B/wake_proof.txt`, do nothing else, exit.
2. `register("B", prompt_file=...)` → `task: MTS-SuccWake-B | fire_at: 2026-10-28T06:26Z | why: pacer NORMAL slots 2: now` (fire now). Real B pacer reading adopted: `pacer_mode=NORMAL slots=2 five=47.0 week=26.0`.
3. Task started; the headless successor booted, read `F:/MTS/succ_wake/B/USAGE`, and wrote the proof file.

**Evidence the woken session did its work** — `F:/MTS/succ_wake/B/wake_proof.txt`:
```
WAKE_PROOF login=B pacer_mode=NORMAL slots=2 five=47.0 week=26.0
```
These four fields are exactly what `USAGE` handed it (`F:/MTS/succ_wake/B/USAGE`, captured above): `pacer_mode="NORMAL"`, `slots=2`, `five_pct=47.0`, `week_pct=26.0`. The woken session read its own usage off disk — the point of the task.

**Evidence the headless run completed** — `F:/MTS/succ_wake/B/out.log` (UTF-16LE, BOM `FF FE`; first line is the runner's status, the log's own header bytes are why a naive UTF-8 read looks garbled):
```
I haven't committed or shipped the three uncommitted files, because they aren't mine.
My only change was the proof file at F:/MTS/succ_wake/B/wake_proof.txt, which is outside the repo.
...
Whoever owns those edits needs to commit and ship them.
```
`err.log` is 0 bytes — the session ran clean and exited on its own.

**Evidence the task unregistered itself** — after the run, `schtasks /Query /TN MTS-SuccWake-B` returns:
```
ERROR: The system cannot find the file specified.
```
i.e. the one-shot task `MTS-SuccWake-B` no longer exists — the `finally`-block `Unregister-ScheduledTask` in `run.ps1` removed it. (Pre-run, `MTS-SuccWake-B` and no `MTS-Wake-*` successor task existed either, so this task was created and removed within this proof.)

## Test that fails on the old code
`scripts/dev/test_successor_wake.py` adds three tests; all three **fail on the pre-change `successor_wake.py`** (proven by running them against `git show HEAD:scripts/dev/successor_wake.py`):
- `test_usage_handoff_written_next_to_prompt` — the old script's `build_script` had no `USAGE` here-string / `Budget handoff:` prompt line (assertion fails).
- `test_usage_missing_plan_is_noted` — `W.wake_usage` did not exist (AttributeError).
- `test_wake_usage_pure_shape` — `W.wake_usage` / `W.usage_rel` did not exist (AttributeError).

With the fix all 16 tests in the file pass.
