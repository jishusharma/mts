**Balance and imbalance in our codebase are reduced to a 60-minute ATR compression box (`MyTradingSys/backtest/layers/fabio/v3/signals.py:183-205`) and a 6-bar close count outside a 24h UTC Value Area (`MyTradingSys/research/tom_fabio_course_correction_2026-11-07/auction_context.py:724-744`), completely omitting the traders' actual context engine: classifying session/weekly profile shapes (`D`/bell-curve vs `P`-shape with `POC > 50%` vs `b`-shape vs `double distribution`), merging overlapping daily cash-session profiles into multi-day balances, tracking consecutive VPOC migration (`2 higher / 2 lower VPOCs`), and using that shape/phase read to switch between counter-trend edge fades and trend/breakout models.** Because our code never classifies whether the prior or developing session profile is a symmetric `D` bell curve, an imbalanced `P`/`b` skew, or a `double distribution`, it fires breakout models inside balance and counter-trend fades against active P/B value migration.
