## Detailed Notes on Filters, Fallbacks, and Windows Flags

1. **How it picks the next task**:
   - Parses `BUILD_PIPELINE.md` into structured rows (wave, num, id, slug, status, blocker, next) via `scripts/sched/pick_task.py:69-82`.
   - Sweeps unscheduled OPEN / IN-FIX bugs from `BUGS.md` into one wave after the highest pipeline wave via `scripts/sched/pick_task.py:99-110`.
   - Sorts all candidate rows by wave and numeric row sequence `(r["wave"], [int(x) for x in r["num"].split(".")])` via `scripts/sched/pick_task.py:374-375`.
   - Filters candidate rows through `skip_reason()` (`scripts/sched/pick_task.py:127-152`): requires `status == "QUEUED"`, no `"operator"` in blocker string, all dependency row numbers must be `"LANDED"`, bugs must have an item doc in `ITEMS` and not already have landed in git commit log (`landed_in_git()`), and pipeline rows must name a file matching `FILE_RE`.

2. **Lane and Host Filters**:
   - Lane/Host filtering in `pick_task.py` is implicit in queue design: `pick_task.py` dispatches queue rows strictly by wave order, dependency status, and non-conflicting file sets (`scripts/sched/pick_task.py:209-243`). Host/lane separation is enforced upstream in task assignments and downstream in session runners (`MTS-<UTC>-CLI-BLD-<slug>`).
   - Host/environment isolation is parameterized via `MTS_PICK_ROOT` test fixture hook (`scripts/sched/pick_task.py:39`).

3. **What it prints when none is runnable**:
   - When no row is pickable (either pipeline is empty, or all pickable rows are blocked/invalid):
     - Archives any prior prompt via `archive_prior()` (`scripts/sched/pick_task.py:388`).
     - Resets state: `atomic_write(QUEUE / STATE_NAME, "{}\n")` (`scripts/sched/pick_task.py:389`).
     - Writes prompt: `atomic_write(QUEUE / "next_task.txt", "IDLE no pickable row\n")` (`scripts/sched/pick_task.py:390`).
     - Logs line: `log_line({"ts": iso, "result": "IDLE"})` (`scripts/sched/pick_task.py:391`).
     - Prints to stdout: `"IDLE no pickable row"` and exits 0 (`scripts/sched/pick_task.py:392-393`).

4. **Creationflags Edit**:
   - In `landed_in_git(rid)` (`scripts/sched/pick_task.py:113-120`), git invocation runs via `subprocess.run(..., creationflags=getattr(subprocess, "CREATE_NO_WINDOW", 0))`.
   - SOURCED commit `c0354cca92cf` (2026-11-11): `"no-window flag on 35 unattended subprocess calls outside scripts/dev (q-5aeda0)"`.
   - This ensures background scheduled picker wakes on Windows do not flash console pop-up windows.
