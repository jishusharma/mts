## Proposed tests

1. Add recovery tests for missing/corrupt `auto_trades.jsonl`, failed process enumeration, and two live managers for one account. Prefer retaining an explicit uncertain slot or stopping new entries when recovery evidence is unavailable.
2. Exercise the real exception conversion in `exchange_flat` for authentication and position API failures, including restoration of the prior `MTS_ACCOUNT` environment value.
3. Exercise `place` with plan refusal, executor API error, timeout, and OS launch error. Returned errors should leave the slot free; raised exceptions currently escape `cycle` and `main`.
4. Exercise respawn failure and ledger failure; assert the slot remains safely occupied after respawn failure and later polls continue after ledger failure.
5. Exercise unreadable layer alert files, malformed complete JSONL records, and non-object state JSON. Define a fail-closed response for each rather than silently consuming/skipping safety state.
6. Preserve the existing balance boundary test and add an explicit mocked funding/transfer change while ticker output stays fixed; assert the auto-trader's mark/plan result does not depend on account balance data.
