## Mismatches ranked by impact

1. MSB uses every swing, not the most recent (row 14, cc_structure.py:91-132). Emits MSB events for a stale swing that a newer, higher swing already supersedes. Affects event counts of every C08/C10 setup built on classify_msb (cc_setups.py, cc_retest.py); research layer only. Fix = pick the latest confirmed opposing swing at each bar, or amend the definition in FORMULAS.md section 9.
2. Duplicate fee models that disagree (not in FORMULAS.md, listed per the brief). Deribit: sim.py:111-112 taker 0.0005 / maker 0.0 (winner, B080); bt_engine.py:16, cc_bt_adapter.py:17, tom_bt.py:151-152 agree with it; layers/fabio/fabio_of_model.py:43-44 taker 0.00035 / maker -0.00015 DISAGREES, and its own docstring line 26 says taker 0.05% / maker 0.02% (a third set, stale). layers/fabio/run_backtest.py:41 FEE_ROUND_TRIP 0.0010. Binance: positioning/trade_costs.py:47 fee_rt 0.0010 + slip 0.0002 (section 13, consistent with run_t055.py:111,195,352-353). Net effect: fabio R results are not comparable with sim/tom_bt results.
3. Executor loss estimate is a second formula for 11.6 (row 30, executor.py:253,336): -size*pct instead of -size*|E-S|/E with snapped S. Conservative (over-states loss), low risk, but the B079 pre-check and the post-fill guard compare a different number than plan_compiler reports.
4. Fractal swing drops the low when a bar is both a fractal high and low (cc_structure.py:43-58, `elif`). Definition silent; probe bar body 9..11 amid bodies 10..10 returned only 'high'. Low impact.
5. tf_resample days buckets return float epoch-ms (tf_resample.py:29-37) while seconds/week/month return int. Values equal, dict keys hash equal, but JSON/str output differs ('1790553600000.0'). Cosmetic, can bite string joins.
