## 2. Shipping Speed Optimization (Halving Ship Time)

### 2.1 Why the Previous Benchmark (`PROOF.md`) Failed the 50% Target (+12% Slower)
In `shipping_speed_2026-10-19/PROOF.md`, measured on JIS-NUC:
- Baseline smoke gate (`nowin.py` changed): **23.022 s** (ran 6 steps: `3gd`, `3dl`, `3tl`, `3x`, `3w`, `4f`).
- Fast smoke gate (`--fast`): **25.794 s** (**+12.04% slower!**).

**Root causes identified:**
1. **Transitive Over-Packing (`FAST_BUDGET_S = 30`):** The budget allowed `plan_budget` to pack up to 90 worker-seconds of 2-hop transitive test steps into the fast gate, pulling in `3xt` (21.7s running `test_lab_flow.py`, `test_sched_scripts.py`, `test_testnet_canary.py`), `3lm`, `4e`, `4g`, and `4d` (13 steps ran instead of 6!).
2. **Forced Doc Tests on Code Changes (`FAST_ALWAYS`):** `FAST_ALWAYS` contained `"4d"`, forcing doc contract pytest (7.4s on NUC, 30s on laptop) on pure `.py` changes where zero docs changed.
3. **Subprocess Spawning Bottleneck in Task Lint (`3tl`):** `tasks.py lint` ran sequential `git rev-parse` and `git log` subprocesses for every ready card (100+ cards), taking **54.3s** on laptop.
4. **Full AST Scanning in CI Deps Lint (`3dl`):** `ci_deps_lint.py` scanned and parsed all 500+ test files even when only a small script was touched.

### 2.2 Fixes Implemented

1. **Subprocess In-Memory Caching (`scripts/dev/task_state.py` & `tasks.py`):**
   - Added `_SHALLOW_CACHE` and `_LAST_CHANGE_CACHE` in `task_state.py`.
   - Cleared caches per lint command run in `cmd_lint()`.
   - Updated `review_hashes(..., need_sha=False)` to avoid redundant sha lookups for non-review cards.
   - **Measured result:** `tasks.py lint` runtime dropped from **54.343s down to 13.166s** (**-75.8% reduction**).

2. **Graph Impact Cache & Fast Budget Capping (`scripts/dev/gate_impact.py`):**
   - Added `_repo_index(root)` in-memory caching for `REPO` in `gate_impact.py` so the ~900 `.py` files are not repeatedly walked.
   - Lowered `FAST_BUDGET_S = 8` (so direct tests always run, but transitive unselected tests are strictly bounded).
   - **Measured result:** `test_gate_impact.py` runtime dropped from **39.198s down to 30.667s** on laptop (-21.8%), and on NUC drops from 8.4s to ~1.5s.

3. **Smart Doc Step Gating & Pytest Shard Batching (`scripts/dev/run_all_tests.py`):**
   - Moved `"4d"` from `FAST_ALWAYS` to `FAST_COSTLY_ALWAYS`. It now only runs if markdown docs or doc tests are touched (`any(gate_select._is_doc(f) for f in files)`), saving **7.4s on NUC / 30s on laptop** on code changes.
   - Added Pytest shard batching: When total kept pytest files across shards `<= 6` and estimated time `<= 15s`, they run in a **single** batched pytest process instead of spawning 3-4 separate pytest processes.

4. **Targeted CI Dependency Linting (`scripts/dev/ci_deps_lint.py`):**
   - Added `--entries` CLI support to `ci_deps_lint.py`.
   - In `run_all_tests.py:apply_fast`, when `.github/workflows/ci.yml` is untouched, `3dl` only lints the test files reached by the change (or skips if no test files are reached).
   - **Measured result:** `ci_deps_lint` on reached test files runs in **1.18s** vs 10.2s (**-88.4% reduction**).

## 3. Starting Context Optimization (Halving Boot Context)

### 3.1 Baseline Context Overhead
A standard Claude or role session boot loaded the following repo files (`CLAUDE.md` Boot steps 1–4):
- `CLAUDE.md`: 6,711 B (~1,678 tokens)
- `STATUS.md`: 5,969 B (~1,492 tokens)
- `ANNOUNCEMENTS.md`: 6,105 B (~1,526 tokens)
- `NEXT_SESSION.md`: 19,744 B (~4,936 tokens)
- `ROLES.md`: 10,610 B (~2,652 tokens)
- *Total core boot context:* **49,139 B (~12,284 tokens)**
- Plus `ROUTING.md`: 13,637 B (~3,409 tokens) -> Total **62,776 B (~15,694 tokens)**.

For role sessions (e.g., `Pipeliner`):
- `roles/pipeliner.md` Boot step 4 required loading 8 whole files: `ANNOUNCEMENTS.md`, `ROUTING.md`, `ROLES.md`, `HOW_MTS_RUNS.md`, `DSA_DELEGATION.md`, `SUPER_SESSION.md`, `WORKERS.md`, `CLOUD_ACCOUNTS.md` totaling **81,040 B (~24,100 tokens)**!

### 3.2 Actions Taken & Reductions Achieved

1. **`NEXT_SESSION.md` Handover Archive (`pipeliner-boot-diet` / `doctor`):**
   - Extracted 6 completed historical handover blocks from 2026-10-18 and 2026-10-19 into `MyTradingSys/system/handoff_history/2026-10-19_trim.md`.
   - Preserved active workload split (2026-10-19 ~20:00 IST) and pointer to archive.
   - **Result:** Cut from **19,744 B -> 2,900 B** (**-85.3% reduction / -4,211 tokens**).

2. **`ROLES.md` Slim Index Table (`roles-md-index-slim` card):**
   - Removed massive duplicated paragraph table.
   - Consolidated into a single clean table: Role, File link, Purpose, Model, Where/Lease.
   - Preserved all 3 mandatory policy rules (`no compaction`, `never the live tree`, `never read .secrets/`).
   - Retokened and verified with `role_loader.py check` (all 9 roles OK).
   - **Result:** Cut from **10,610 B -> 2,477 B** (**-76.7% reduction / -2,033 tokens**).

3. **`ANNOUNCEMENTS.md` Trim:**
   - Condensed `## EXPIRED` entry `A-20261018-5` to a 1-line note.
   - **Result:** Cut from **6,105 B -> 4,460 B** (**-26.9% reduction / -411 tokens**).

4. **`roles/pipeliner.md` Boot Diet (`pipeliner-boot-diet` card):**
   - Replaced whole-file loading in Boot step 4 with section pointers:
     `Read origin/fast-track MyTradingSys/system/ANNOUNCEMENTS.md (ACTIVE section), ROUTING.md, CLOUD_ACCOUNTS.md, and sections as needed: WORKERS.md (rules 3, 5), ROLES.md (Index table). Other files are referenced on demand, not loaded at boot.`
   - **Result:** Pipeliner boot context dropped from **24.1k tokens down to ~6.2k tokens** (**-74.2% reduction / -17,875 tokens**).
