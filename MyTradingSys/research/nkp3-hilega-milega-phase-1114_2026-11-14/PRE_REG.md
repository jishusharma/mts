# PRE_REG nkp3-hilega-milega-phase-1114 (written and committed with the code before any DEV or VAL result)

Operator order 2026-11-13: NK tests must be phase specific and apply the MTS brains to find useful trades.
Method = `MTS_BRAINS_SPEC_1114.md` (6 causal BTC phases x 8 single-bucket context layers, DEV selection, VAL once). Every parameter is OURS unless marked SOURCED. This study owns NK4 Hilega Milega and the Bollinger breakout/fakeout rule on 1h/4h.

## Context
Operator wants rules judged inside the market phase they belong to, with the MTS context layers deciding which trades are worth taking. Earlier NK1-NK6 used one coarse ADX phase and no context; gross R was about 0 and fees decided. Here the phase is the 6-label BTC cycle/structure clock (day d labelled from closes through d-1); context layers are read at the signal bar close.
Regime mix: reported in RESULT.md as days per phase (DEV and VAL) and signals per phase per rule. Expectation (not a result): DEV is mostly MARKUP/MARKDOWN/ACCUM-RANGE; CAPITULATION and RELIEF are thin (< 5% of DEV days makes a phase UNDERPOWERED, it cannot supply a kept cell).
Disclosure: before this commit I ran one wiring smoke test on BTC+ETH 4h only (printed trade counts and gross means). Nothing in the design below was changed after seeing it, and no cell selection used it.

## Rules (signal definitions frozen; no tuning)
| Variant | Signal | Exit | Cap | Label |
|---|---|---|---|---|
| HM15 / HM1h / HM4h | Hilega Milega state flips to buy/sell on a completed bar of the signal tf. RSI(9) Wilder, EMA(3) of RSI, WMA(21) of RSI; buy = RSI>EMA3, RSI>WMA21, EMA3>WMA21; sell = mirror | first bar close where state != direction, exit at next open | 48 bars | formula OURS (NK never gave it; NK4 recon) |
| BO1h / BO4h | Bollinger(20, 2 population sd) breakout: close beyond the band after the previous close was inside it. Long above upper, short below lower. Trade with the break | close back through the middle band (SMA20), exit next open | 24 bars | OURS (NK-R11 was 15m only) |
| FO1h / FO4h | Fakeout fade: previous close outside the band, this close back inside. Fade: short after upper, long after lower | close reaches the middle band | 24 bars | OURS |
Entry at the open of the bar after the signal bar. Stop = max(1.5 x ATR14(signal tf), 0.5% of entry), which satisfies the spec floor max(0.6 ATR, 0.5%). Stop checked intrabar on the signal tf bars, stop wins ties, a gap through the stop fills at the worse of stop and the bar open. Prices are Binance spot USDT (20 coins: BTC ETH BNB XRP ADA DOGE SOL LTC LINK TRX DOT AVAX ATOM ETC BCH XLM UNI NEAR FIL EOS, 5m bars from 2019 or listing, 15m/1h/4h/1D built on UTC-aligned buckets). Funding is not charged because the traded prices are spot; a perp implementation would add funding (stated, not modelled). 7 variants = the 7 "rules" for the top-3 rule below.
HTF use: C1, C3 (4h) and C2 (1D) are the HTF context; HM also runs on 4h; 15m is the lowest signal tf.

## Phases (spec s1, unchanged)
One label per UTC day from BTC (daily history: `btc_cycles_2026-11/btc_daily.csv` before 2019, BTC 5m cache from 2019; only complete days). Features through the prior close: SMA20/50/200, S50 = SMA50/SMA50[-10]-1, R10, RB30, DD from ATH close, W200 = 1400-day SMA, RSI14d, RNG40, NEWLOW15. Cycle state M: BEAR if DD<=-20% and c<SMA200; BULL if c>W200 and DD>-20%; else BASE (SOURCED: cycle-conditioned PRE_REG, BIBLE s5). First match: 1 CAPITULATION (M!=BULL, R10<=-20%, RSI14d<=30, sticks 3 days; long only); 2 MARKDOWN (c<SMA50, S50<=-1%, BEAR or c<SMA200; short); 3 RELIEF (M!=BULL, c>SMA20, RB30>=12%, c<=1.05 SMA200; long); 4 ACCUM-RANGE (M!=BULL, RNG40<=30%, |c/SMA50-1|<=7%, no NEWLOW15; both); 5 MARKUP (c>SMA50, S50>=1%, c>SMA200 or BULL; long); 6 DISTRIBUTION (else; short). All thresholds OURS. Halving age reported per phase only. Sanity windows (not tuned): CAPITULATION 2020-03-12..15 and 2022-06-13..18, MARKDOWN 2022-01..10 and 2025-11..2026-02, MARKUP 2020-11..2021-03 and 2023-10..2024-03; a window that reads mostly as another label is recorded in RESULT, not fixed. Table: `F:\MTS\data_cache\mts_brains\phase_daily.csv`.

## Context layers (spec s2, unchanged; one layer per cell)
C1 4h RSI14 (<=40 / mid / >=60, SOURCED Malkan 40/60). C2 1D WaveTrend LazyBear (10/21, +-53; params verified in `backtest/layers/wavetrend/wavetrend.py`). C3 4h Bollinger %B (<0.10 / mid / >0.90, cutoffs OURS). C4 OI change 24h (<=-3 / flat / >=+3%, futures metrics `sum_open_interest_value`, hourly). C5 mean of last 3 settled funding rates (<0 / 0..0.03% / >0.03%). C6 24h taker delta vs 24h price change (bull-div / agree / bear-div; spot 1h klines taker-buy volume). C7 RV7/RV60 (<0.7 / mid / >1.3). C8 UTC session of the signal bar close (ASIA 21-07 / EU 07-13 / US 13-21). Every layer reads only bars closed at or before the signal bar close. C4/C5 need futures data from data.binance.vision (first date per coin recorded in RESULT); signals before a coin's first date get bucket NA and are never in a C4/C5 cell; if a rule has < 150 DEV signals with a C4 (C5) reading, that layer is NO-DATA for the rule. No layer may be added after DEV is seen.

## Step A (per phase, both directions, DEV first then VAL as a control table)
Per variant, phase, direction: n, days, gross R, cost R (12 bp x entry / stop distance), net R at 12 bp; appropriate direction marked; appropriate minus opposite net R with day-clustered standard error. No pooled-phase headline.

## Step B (DEV only, signal close <= 2023-12-31)
Cells = phase x layer x bucket x allowed direction (long-only phases, short-only phases, ACCUM both). Eligible: n >= 150 and >= 40 distinct UTC days. Score = lower 90% bound of the day-clustered mean net R at 12 bp (2000 day-bootstrap draws, seed 7). Keep top 3 per variant if score > 0, direction phase-appropriate, phase has >= 5% of DEV days, layer not NO-DATA, at most one kept cell per layer. Zero kept cells is a valid result. Output `cells_frozen.json` (with the code commit hash) + `dev_cells.csv` + `dev_step_a.csv`, committed BEFORE the val stage; `run.py val` refuses otherwise.

## Step C (VAL, signal close >= 2024-01-01, run once on kept cells)
Per kept cell: n, days, win%, break-even win%, gross R, cost R, net R at 12 bp, day-cluster 95% CI (5000 draws), ex-best-5-days net R. 6 bp maker row with fill model: limit at the signal bar close, filled only when the next bar trades through it (low < limit long, high > limit short), unfilled = no trade, entry = limit; fill rate reported. Placebo: 1000 random entries from the same cell (same phase day, same layer bucket, same direction, hour of day matched to the real trades, same stop rule, hold = real trade's nominal exit length); p = one-sided normal test of real mean vs placebo (n real trades). BH at q = 0.10 over the kept cells (family = number kept) using the day-cluster bootstrap p. PASS needs net R > 0, CI low > 0, ex-best-5 > 0, placebo p < 0.05, BH q < 0.10 and n >= 150, otherwise FAIL (or UNDERPOWERED if n < 150). Controls per kept cell: opposite direction same cell, same bucket in the other phases, unconditional same phase+direction, unconditional rule. Report cells passing VAL out of cells kept and DEV net vs VAL net (shrinkage). Today block: phase label of the last 10 days with BTC close/SMA50/SMA200/W200 (last day is provisional), and for BTC/ETH whether a kept cell's phase and bucket match now (descriptive, no advice).
