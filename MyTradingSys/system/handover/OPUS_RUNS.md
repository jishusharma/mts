## Gateway: the same runs in the background, no new app window
Start line, typed into ONE Code session on the station (any login; it is only the launcher and spends little):

    Run OPUS_RUNS.md gateway O1 O2

(or any list; the launcher starts O3 itself after O1 ships). Each run is a headless `claude -p` child billed to the gateway.
1. Gateway reach test, names only, never a value: if `~/.mts_gateway/env.ps1` exists (operator file outside the repo; sets the gateway base URL and key for the child only), use it; else if this session's env has `ANTHROPIC_BASE_URL` set (the app runs the Gateway profile), children inherit it; else stop and reply "no gateway: children would bill the login". Check with `Test-Path` and `[bool]$env:ANTHROPIC_BASE_URL` only; never print, cat or copy the file or the variables.
2. Probe: one child `claude -p "reply OK" --model claude-opus-5-5 --output-format json` (same env source). Keep only `is_error`, the `modelUsage` keys and `num_turns`. Error, or no Opus key: stop and reply with the error line.
3. Per run: `git -C <repo> worktree add .claude/worktrees/gw-<card> -b gateway/<card> origin/fast-track`, write `.gateway_owner` in it, then start the child with the Bash tool `run_in_background` (a running session, not a scheduler) in that folder: `pwsh -NoProfile -Command "$env:MTS_GATEWAY='1'; . ~/.mts_gateway/env.ps1; claude -p '<child prompt>' --model claude-opus-5-5 --permission-mode dontAsk --allowedTools 'Bash Read Edit Write Glob Grep Agent' --output-format json"` (drop the dot-source when the env comes from the app), stdout to `gateway_runs/<card>.json` in the launcher tree (gitignored). At most 2 children at once (one shared key across stations).
4. Child prompt: "You run on the MTS gateway, headless. Public tracked files only (GATEWAY_NUC.md rules 1-7): never read .secrets, .env, keys, runtime, the live tree or F:/ backups. You are already in your worktree; skip sync.py start. Run OPUS_RUNS.md <O1|O2|O3> in full. Skip get_usage: write 'gateway: no meter'. Commit body adds 'Model: claude-opus-5-5 via gateway'. Never ask; take the conservative default and log DECISION (OURS)."
5. When a child exits (the background notice): read its json (`is_error`, `num_turns`, `modelUsage` keys, last 400 characters of `result`); `git fetch`; the run's commit must be on origin/fast-track (`git cherry origin/fast-track gateway/<card>` empty) and its new tests pass there (GATEWAY_NUC.md rule 4 spot-check). A 429 or overload is a wait: relaunch once on the next notice; a second one goes in the reply. O1 shipped: start O3.
6. Reply: table run | commit on trunk | model key | turns | spot-check; then `git -C <repo> worktree remove` each shipped gw- tree.
DECISION (OURS): the key reaches the child only through a script the operator owns (`env.ps1`) or the app's own profile env; no session reads it, as with the registry file.
