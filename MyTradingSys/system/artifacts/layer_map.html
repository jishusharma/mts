MTS Layer and Backtest Map

This page cannot run a backtest. It is a static map generated from repo files. The configurator at the end only writes a task card you paste into NEXT_SESSION.md; a relay session on the host you name then runs it. Refresh: python scripts/dev/make_layer_map.py, then republish.

Rows are backtests, columns are layers. A dot means the layer was on in that run (as recorded). Click a row title on the Backtests tab for the detail.

Pick layers and parameters

Choices come from what past runs swept. A parameter marked NO-SOURCE has no trader quote: the card tells the run to flag it, never tune it (provenance rule). A new run is a trial: pre-register first, dev data only.
