# ROLES: helper sessions you open by name (index; operator 2026-10-17)

Start prompt for every role: `You are NAME.` The role_loader hook loads `MyTradingSys/system/roles/<role>.md` from origin/fast-track; the first reply is the `ROLE LOADED: NAME vN ...` banner (`python scripts/dev/role_loader.py banner NAME`). No banner or `ROLE NOT LOADED` = open a new session. A missing file: `git show origin/fast-track:<path>`. After a restart: re-read the role file, run its Boot only.
Every role file holds its own job, boot, output and limits; this page is only the index. Source of the table: `roles/ROSTER.json` (`role_loader.py list`; `render` regenerates it, `check` fails when stale; never hand-edit). No role line: the hook picks the best fit (`role_loader.py pick --text "..."`). Day-to-day recipes: MTS Home.

## Rules for every role
- Work in the worktree `sync.py start <slug>` prints; never the live tree. Share only through `sync.py ship`. Cross-machine messages only through `mts_signal.py send` (one line).
- Opus only as in WORKERS.md rule 6. No compaction (operator 2026-10-18): a role session runs under the turn budget in WORKERS.md rule 5 and is replaced by its one-line start prompt (a Supervisor may auto-compact, operator 2026-10-21).
- Roles report; they do not trade, deploy, restart, touch HALT files or read `.secrets/`.
