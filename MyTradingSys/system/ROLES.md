# ROLES: helper sessions you open by name (operator 2026-10-17)

A role = a session started with one line; the role itself lives here, so a lost or over-budget session is replaced by pasting
that line again. Pinning is only a sidebar shortcut. Channels (signals, desk, shot, sync) are unchanged.
How to use them day to day (the few recipes and the paste lines): MTS Home, section "How to use MTS" (source `scripts/dev/make_home.py`).

**Start prompt, identical for every role** (replace NAME): `You are NAME.` The role_loader hook (UserPromptSubmit) loads MyTradingSys/system/roles/<role>.md from origin/fast-track; the first reply must be the `ROLE LOADED: NAME vN · token word-word · <path> @ <sha>` banner (`python scripts/dev/role_loader.py banner NAME` prints the expected one). No banner or `ROLE NOT LOADED` = do not work with that session; open a new one.
**Files a row names** (e.g. `roles/eagle_eyes.md`): if missing locally, read them the same way with `git show origin/fast-track:<path>`.
**After a restart or clear:** re-read the row, run its boot line only, continue.

## Which roles exist and where each runs
Single source: `MyTradingSys/system/roles/ROSTER.json` (name, file, start, model, lane, job, fallback keywords). `python scripts/dev/role_loader.py list` prints it; the table below is generated by `role_loader.py render` (`check` fails when it is stale), so never hand-edit it or type a role count. role_loader.py checks no machine or login: every role starts anywhere.
**No role line?** The hook loads the best-fitting operator role from the session's first prompt (`role_loader.py pick --text "..."` shows the choice), banner `ROLE LOADED: <Name> (fallback: <why>) ...`; on a tie it asks once; embedded roles are never picked; briefs from another session are left alone.

## Rules for every role
- Work in the worktree `sync.py start <slug>` prints; never the live tree. Share only through `sync.py ship`. Cross-machine messages only through `mts_signal.py send` (one line); long requests are a desk task, the signal points to it.
- Opus only as in WORKERS.md rule 6. Scoped sub-work goes to Haiku Agents (rule 3a, at most 5 at a time).
- No compaction (operator 2026-10-18): a role session runs under the turn budget in WORKERS.md rule 5 and is replaced by its one-line start prompt when it is over it.
- Roles report; they do not trade, deploy, restart, touch HALT files or read `.secrets/`.
